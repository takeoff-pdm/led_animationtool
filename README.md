# LED Stripe Animationtool
Animationtool for Led tubes/strips written in Python. It features/will feature beatsync, strobo, rainbow animations, managable with an UI and more.

**Developed for Raspberry Pi's and Arduino's**

## Animation Limits
217 BPM is the limit for every fading animation. Going beyond this speed may result in bad looking animations, while non-fading animations are able to get a lot faster than that.
